# CHU Admin Dashboard

Administration dashboard for a hospital (CHU) built with Next.js and Tailwind.

## Features

- Admin layout with Flowbite components
- Font Awesome icons
- Responsive Tailwind UI

## Tech Stack

- Next.js
- React
- Tailwind CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/chu-admin-dashboard.git
cd chu-admin-dashboard
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
